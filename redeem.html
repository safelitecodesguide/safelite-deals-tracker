Redeeming a deal at checkout

Where the promo field hides, and what to do when a code won't apply.

Step by step

  1. Get a quote on safelite.com — enter your ZIP, vehicle, and glass damage.
  2. Choose pay on my own (not the insurance path — codes don't work on insurance claims).
  3. On the quote/booking screen, look for the "I have a promo code" link near the price summary.
  4. Paste the code and apply it. Check that a discount line appears and the total drops — that confirmation is the whole test.
  5. If it works, finish booking. If not, see the troubleshooting list below.

When a code won't apply

  • "Promo code is not valid": the deal has died or the code was mistyped. Try the next live deal on the board.
  • Wrong service type: repair-only codes (SAFELITEHEROREPAIR20, WEB15SL, MIL25) won't apply to a replacement quote, and replacement-only codes won't apply to a repair quote.
  • Insurance path: the promo field appears there too, but codes are not valid on insurance claims per Safelite's terms. Switch to pay-on-my-own.
  • Commercial or fleet: excluded from these offers.
  • One code per order: a second code won't stack — entering one replaces the other.
The one rule that matters: never assume a code worked. The discount line in your own quote is the only confirmation that counts — that is exactly how this board's statuses are recorded.
