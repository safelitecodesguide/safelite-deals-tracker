# Safelite Deals Tracker (Cloudflare Pages)

Static site — deal-status board for Safelite promo codes, checkout-tested Oct 21, 2026.

Deploy (owner, from Cloudflare account): Cloudflare dashboard -> Pages -> Connect to Git -> select this repo (safelitecodesguide/safelite-deals-tracker). Framework preset: None. Build command: leave empty. Build output directory: / . Production branch: main.

After the project is created, replace YOUR-PROJECT in canonical tags, sitemap.xml and robots.txt with the real project subdomain (e.g. safelite-deals-tracker.pages.dev).
