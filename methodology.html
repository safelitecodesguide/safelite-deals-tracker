Deal Board / Methodology

How the board is checked

No scraped lists, no copied expiry dates. Just checkout tests.

The check, every two days

  1. A standard quote is built on safelite.com (sample: 2022 Toyota Camry, ZIP 30303, pay on my own).
  2. Each tracked code is entered in the promo field at checkout and the result is recorded.
  3. A code counts as Live only if a discount line appears and the total drops. Anything else — including "promo code is not valid" — moves the code to the dead board.
  4. New candidate codes (from Safelite's own pages and the web) are tested the same way before they ever appear here.
  5. The board, the history log and every "last checked" date are updated to the check date.

What this board will not do

  • No invented expiry dates. Safelite publishes no expiry for these codes, so the board shows the last check date instead.
  • No copied claims. If a listing site says a code is "active" but checkout rejects it, checkout wins.
  • No percentage math on 10THANKYOU10. It is reported as the dollar amount it produced ($39.08 on the sample quote), because that is what was measured.
  • No "with code" prices that were never tested. The costs page shows post-deal prices only for combinations that were actually run.
